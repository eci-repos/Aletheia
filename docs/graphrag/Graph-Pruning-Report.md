## Purpose

This document describes the subgraph pruning capability in Aletheia LazyGraphRAG. Pruning removes low-relevance nodes and relationships from the temporary query-time graph before context generation, minimizing token consumption and improving retrieval precision.

---

## Interface

```csharp
public interface ISubgraphPruningService
{
    Task<Result<IReadOnlyList<GraphNode>>> PruneNodesAsync(
        IReadOnlyList<GraphNode> nodes,
        string query,
        float relevanceThreshold = 0.3f,
        CancellationToken cancellationToken = default);

    Task<Result<IReadOnlyList<GraphEdge>>> PruneRelationshipsAsync(
        IReadOnlyList<GraphEdge> edges,
        IReadOnlyList<GraphNode> retainedNodes,
        CancellationToken cancellationToken = default);
}
```

---

## Relevance Scoring Algorithm

Each node receives a composite relevance score between 0.0 and 1.0:

| Signal | Weight | Condition |
|--------|--------|-----------|
| Label Exact Match | +1.0 | `node.Label == query` |
| Label Containment | +0.7 | `query.Contains(label)` or `label.Contains(query)` |
| Query Term in Label | +0.15 | per matching term |
| Query Term in Type | +0.05 | per matching term |
| Query Term in Properties | +0.05 | per matching term in string properties |

Scores are clamped to a maximum of 1.0.

## Usage in LazyGraphRagService

```csharp
// After LLM-guided traversal
var traversedNodes = await TraverseWithReasoningAsync(query, tempGraph, ct);

// Prune low-relevance nodes (default threshold: 0.25f)
var prunedNodes = await _pruning.PruneNodesAsync(
    traversedNodes, query, relevanceThreshold: 0.25f, cancellationToken);

var prunedNodeList = prunedNodes.IsSuccess && prunedNodes.Value is not null
    ? prunedNodes.Value.ToList()
    : traversedNodes.ToList();
```

The lowered threshold (0.25 vs default 0.3) allows more nodes through for community resolution while still filtering noise.

## Pruning Behavior

### Node Pruning

1. Compute relevance score for every node in the subgraph.
2. Retain nodes with `score >= relevanceThreshold`.
3. Sort retained nodes by descending score.
4. Return ordered list.

### Edge Pruning

1. Build a set of retained node IDs.
2. Filter edges to only those where both `SourceId` and `TargetId` are in the retained set.
3. Return pruned edge list.

This ensures no dangling edges remain in the final subgraph.
