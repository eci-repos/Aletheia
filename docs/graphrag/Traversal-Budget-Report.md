## Purpose

This document describes the cost-budgeted traversal system in Aletheia LazyGraphRAG. All graph exploration during retrieval is constrained by a configurable resource budget to control latency, token consumption, and LLM API costs.

---

## Interface

```csharp
public interface IGraphTraversalBudget
{
    int MaxLLMCalls { get; }
    int MaxDepth { get; }
    int MaxNodes { get; }
    int MaxRelationships { get; }
    int MaxTokenBudget { get; }
    TimeSpan MaxExecutionTime { get; }

    bool RecordLLMCall();
    bool RecordNodeVisit();
    bool RecordRelationshipTraversed();
    bool RecordTokens(int tokenCount);
    bool IsTimeExceeded();
    bool IsExceeded();
    void Reset();
}
```

## Default Budget Configuration

| Parameter | Default Value | Purpose |
|-----------|--------------|---------|
| MaxLLMCalls | 5 | Prevents runaway LLM invocation cascades |
| MaxDepth | 3 | Limits graph traversal depth |
| MaxNodes | 50 | Caps the subgraph size |
| MaxRelationships | 100 | Limits edge exploration |
| MaxTokenBudget | 4000 | Controls token consumption for context |
| MaxExecutionTime | 30 seconds | Hard timeout for retrieval |

## Enforcement Points

### In LazyGraphRagService.RetrieveAsync

```
1. Entity Discovery
   if (!_budget.RecordLLMCall()) return fallback;

2. Relationship Discovery
   if (!_budget.RecordLLMCall()) return empty;

3. LLM-Guided Traversal
   while (frontier.Count > 0 && !_budget.IsExceeded())
   {
       if (depth >= _budget.MaxDepth) continue;
       if (!_budget.RecordNodeVisit() || !_budget.RecordRelationshipTraversed()) break;
       ...
   }

4. Community Resolution
   foreach (var node in nodes.Take(5))
   {
       if (!_budget.RecordLLMCall()) break;
       ...
   }

5. Summary Retrieval
   foreach (var node in nodes.Take(3))
   {
       if (!_budget.RecordLLMCall()) break;
       _graphSummary.SummarizeEntityAsync(...);
       _hierarchicalSummary.SummarizeEntityAsync(...);
   }
```

### Budget Exhaustion Behavior

When any budget limit is exceeded:

| Stage | Behavior |
|-------|----------|
| Entity Discovery | Falls back to simple keyword extraction (no LLM) |
| Relationship Discovery | Returns empty relationship list |
| Traversal | Stops expanding frontier; returns current subgraph |
| Community Resolution | Skips remaining community lookups |
| Summary Retrieval | Skips remaining summary generation |

If the overall budget is exceeded before semantic retrieval completes, the service returns a failure result with message `"Traversal budget exceeded during {stage}."`.

## Thread Safety

`GraphTraversalBudget` uses `Interlocked` operations for all counters:

```csharp
Interlocked.Increment(ref _llmCalls);
Interlocked.Increment(ref _nodesVisited);
Interlocked.Increment(ref _relationshipsTraversed);
Interlocked.Add(ref _tokensConsumed, tokenCount);
```

This ensures safe concurrent access if multiple retrieval operations share a budget instance (not recommended; use `Reset()` per-query).

## Customization

Budgets can be configured at DI registration time:

```csharp
builder.Services.AddSingleton<IGraphTraversalBudget>(sp => new GraphTraversalBudget(
    maxLLMCalls: 10,          // Higher for complex queries
    maxDepth: 4,              // Deeper traversal
    maxNodes: 100,            // Larger subgraph
    maxRelationships: 200,    // More edge exploration
    maxTokenBudget: 8000,     // Larger context window
    maxExecutionTime: TimeSpan.FromSeconds(60)));
```

For per-request budgets, inject a factory or create a new instance per `RetrieveAsync` call.
